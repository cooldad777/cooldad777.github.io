How the multi-AI mechanic works

One model can stumble through a single challenge; the page is built so the full unlock wants several lenses. Try the pattern yourself, send the reflection prompt to ChatGPT / Claude / Gemini / a local model and paste the line, then use another pass (or a friend) to reason about combine-order. Fragments are deterministic from the UTC date — same day, same lock, everywhere.

  1. Voice I — pattern / sequence (local).
  2. Voice II — paste a model’s one-line reflection (soft keyword / honor check).
  3. Voice III — order the three fragments into today’s phrase.

Client-side checks with light obfuscation — engagement theater, not a security boundary. No accounts, no private data, no real exploit. Modern bits used when available: View Transitions, CSS scroll-driven animations, Popover API, container queries, Web Share, Clipboard, Web Animations — all progressive.
