How to read this

The method page states what would be recorded, what would not, and the twelve definitions. Those definitions are the method.

The scenario page is HS-001, Ambiguity, version 1.0. The three responses are fiction, in slots named Model A, Model B, and Model C. Any ordinal mark is illustrative. Sample size: unknown / not run.

Nothing on these pages is a leaderboard. Nothing names a product, because nothing was run.

Related research thread

Portable human boundaries

Human Signal is not only about comparing model behavior. One adjacent research question is whether a person can carry a small, explicit boundary profile across AI systems: how they want uncertainty handled, how they want flattery and attachment cues treated, and which decisions must remain theirs.

Anti-Attachment is the public-interest prototype for that idea. It is a human-readable framework, not a claim that a Markdown file can control arbitrary models. The receiving system still has to read and honor the boundary.
