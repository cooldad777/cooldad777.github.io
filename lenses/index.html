Same facts. Different honest vantages.

A lens is useful when it reveals something. It becomes dangerous when it pretends it can see everything.

How to use this page. Pick a claim, run it through more than one lens, and keep the disagreements visible. This is not an endorsement map.

C. S. Lewis
