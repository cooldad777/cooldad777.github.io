Method · Cross-model

Universal Markdown Doctrine

Markdown is the shared language; the index is the lens; load the smallest true file.

Why MD (not a proprietary memory store)

  1. Opens on every model, every OS, behind SSO or on a phone.
  2. Diffs cleanly — you see drift.
  3. Survives vendor churn (models are rented; files are owned).
  4. Forces point, don’t paste — URLs/paths beat 200k-token dumps.

Load order (token filter)

  1. This doctrine (or a short stub that points here).
  2. The relevant INDEX for that home.
  3. Only the one Settled/Confirmed file the task needs.
  4. Stop. If missing → say missing. Do not invent.

Tiers as anti-hallucination rails

TierModel mayModel must not
Settled (gold)Treat as load-bearing truth for this homeContradict without flagging
Confirmed (silver)Use with date/sourcePresent as timeless
Raw (bronze)Search / proposeAssert as fact
AbsentSay “not in canon”Fabricate a citation

Membranes

  • Personal Seer never receives employer facts.
  • Work/Rutter never receives personal archive bytes — only publishable patterns that passed the gate.
  • Public website/git = only graduate-gate content.

How to load a stub (≤30 lines)

You are operating inside the SEE, R / Seer system.
1. Read the Universal MD Doctrine (this page / doctrine.html).
2. Use the INDEX for the active home only.
3. Load the smallest Settled file needed. Do not ingest the whole library.
4. Label facts vs interpretation. If not in Settled canon, say so.
5. No employer facts in personal context; no personal archive in work context.
