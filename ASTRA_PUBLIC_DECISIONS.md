# ASTRA PUBLIC DECISIONS

| Decision | Reason | Tradeoff |
| --- | --- | --- |
| Lead with a person and five destinations | The umbrella should be legible before a visitor meets specialist concepts | Less atmospheric mystery than the old full-bleed opening |
| Keep the forest and original star | Existing identity works and carries humanity without invented imagery | This is evolution, not a wholesale rebrand |
| Replace homepage cards/tabs with editorial rows | All principal destinations remain visible and work without fetching data | Less apparent interactivity; greater orientation |
| Separate the capability question from the authority question | Makes the central research concern intelligible | A design thesis, not an empirical law |
| Add a three-state fictional boundary walkthrough | Makes scope, permission and correction concrete | It illustrates desired behavior; it does not run or evaluate a model |
| Put primary evidence behind native disclosure | The reader can inspect limits without a wall of specialist prose | Readers must expand a source to see its details |
| Retain HS-001 fixtures without inventing results | Protects the difference between illustration and measurement | Public measured runs remain future work |
| Keep SEER's demo and offer | It already performs the requested question → evidence → validation → human-decision sequence | The professional page receives fewer visible structural changes |
| Remove sales CTAs from research pages | Avoids presenting research as a finished commercial capability | Professional contact requires returning to SEER |
| Use a curated REWIND source reader | Exact excerpts and Git sources preserve provenance without faking old site state | No whole-site version playback; three milestones are an editorial selection |
| Preserve Chronicle JSON byte-for-byte | Public decisions should not be invented or backdated by an implementation pass | No new digest entries announce this unapproved candidate |
| Rename Live to Signals and replace unverified headlines | Dated selection is honest; credible-looking URLs are not verification | Less topical breadth, no automatic news refresh |
| Retain Lenses as a separate tool | Comparing perspectives does not synthesize truth by itself | No universal combined verdict |
| Start Lenses on Compare for phones | Existing spatial map compresses source text excessively on a small screen | Map is available but no longer the mobile default |
| Keep Christian formation explicit | GROUNDED is Scripture, prayer, community and obedience | It is not recast as a generic wellness product |
| Remove commercial scale metrics from GROUNDED | They do not establish the value of the practice | Less numerical spectacle |
| Make audio opt-in per page | A generic navigation gesture should not authorize playback | Cross-page automatic resumption is deliberately removed |
| Remove global pointer-follow and reveal scripts | Movement did not communicate a needed relationship | Less animation; visible content does not depend on an observer |
| Keep standalone tools distinct | Their jobs justify different interfaces | Shared CSS is intentionally not forced onto the fading timer |

## Refusals

No client or employer claims, private imports, internal experimental results dressed as external science, clinical scoring, prophetically identified news, model league table, backend inference, new subscriptions, automatic Chronicle publishing, fabricated historical UI, production deployment, or inspection of the independent Sol branches.
